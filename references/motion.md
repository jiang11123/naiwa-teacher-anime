## 1. 基本单位是字幕段

- **每段字幕都有自己的动作**。一个画面不静止超过 3 秒，不像 PPT
- **元素卡在词上**：说到哪个词，对应的东西当场出来（`T(句, 段)`，要更准就用 `marks` + `M()`）
- **分镜一开场就有主画面**：第一段字幕就出，不等第二段
- **长句拆成几拍**：一句话 6 秒，就拆成 2~3 个动作
- **完整动作**：起势 → 发生 → 结果，有因果。说“拿走”就真的飞出屏幕；钥匙不要“贴一只手拖走”，要机械爪下降 → 合拢 → 拎走

## 2. 出场和退场

按分量选 `kind`：

| kind | 分量 | 用在 |
|---|---|---|
| `fade` / `rise` | 轻 | 辅助信息、胶囊、小字 |
| `pop` | 中 | 卡片、道具（默认） |
| `left` / `right` | 中 | 对比双方、让位时进来的元素 |
| `drop` / `squash` | 重 | 有重量的东西落地 |
| `stamp` | 最重 | 结论、判决词 |
| `flip` | 特殊 | 揭晓答案 |

- **错开，不齐步**：一组元素相隔 4~8 帧依次出来；依次出现要匀速、一个接一个，不要一批批冒出来又停住
- **小组件先出，大组件后出**
- **长时间停留的元素要有呼吸**：`bob`、`usePulse` 鼓一下、`Wobble` 摇一摇，或陆续弹出小件
- **换展板时自动退场**：World3D 在展板结束前 8 帧让所有 `A` 缩回下沉，下一块展板马上接上，不会空屏
- **展板中途退场**写 `out`；分步讲解时上一步的**所有**元素都要退（残留的箭头很显眼）；下一个紧接着出，`out` 和下一个的 `at` 写同一帧
- **说拿走就拿走**：飞走的东西要完全出屏，不能停在画面里，也不能压到标题；抽飞完那帧确认
- **一个东西变成另一个东西**用 `Morph`，不要“旧的退场、新的出场”
- **换字要做真动画**：不能只换一个字、人物还跟着位移（会显得卡）

## 3. 曲线和节奏数字

| 用途 | 曲线 |
|---|---|
| 回弹（重要的东西） | `Easing.bezier(0.34, 1.56, 0.64, 1)` |
| 平滑减速 | `Easing.bezier(0.16, 1, 0.3, 1)` |
| 镜头和位移 | `Easing.bezier(0.65, 0, 0.35, 1)` |
| 退场（加速离开） | `Easing.bezier(0.55, 0, 1, 0.45)` |

这些是用户认可过的手感（Q 弹但不变形）：连续贝塞尔，落地不压扁变形，不拆成多段关键帧。

| 项目 | 值（30fps） |
|---|---|
| 一个画面不静止超过 | 3 秒 |
| 普通入场 | 12~16 帧 |
| 盖章 | 约 11 帧 |
| 退场 | 6~10 帧 |
| 元素切走前至少停留 | 1.5 秒，撑不住就整块删掉 |
| 同样的内容在屏上最多留 | 12 秒（榜单、教程窗口这类贯穿的除外） |

## 4. 3D 展板的镜头

`World3D` 已经做好了镜头，分镜只需要在 `timeline.tsx` 选进场方式：

- `stay`：镜头不动，换组件（段落内默认）
- `keep`：镜头不动，截图窗口原地换内容
- `slide`：平移到右边一块
- `push`：往前推进到更深一块（旧展板在穿过镜头前淡掉）
- `fly`：转身飞到下一个拐角（24 帧，带运动模糊和景深），**只在大段落之间**

镜头停住时只有很轻的左右环视（±2.5°）和慢推，不会大幅绕圈。规则：

- **不要先拉远（先缩小）再转身**，直接转身平滑飞过去
- **转场不挡镜头**：换段落靠镜头推进 / 穿过去，不用盖满全屏的卡片隧道、大按钮
- **别说一两句就换镜头**：段落内都用 `stay`
- 每块展板的取景在 `framing.ts`：默认 `[0.84, 0, 24]`（内容约占 2/3 并居中）；某块内容偏大偏小时在 `OVERRIDE` 里按展板 id 单独写 `[缩放, 横移, 纵移]`
- 铺满全屏的视频展板前，把它的 id 加进 `World3D.tsx` 的 `CUT_BEFORE`，上一块展板直接切掉，不留退场尾巴

**截图窗口里**要看清小字时才推大（`K(帧, 1.7~2.2, 焦点x%, 焦点y%)`），推到位就停住，不整段慢慢漂。

**2D 平面模式**的镜头写在分镜表第 5 列（见 modes.md 第 2 节）：第一帧居中；推近多用 1.04~1.06，焦点别偏远；推的方向要有理由。

## 5. 3D 实景（办公室 / 街道）

主比喻是一个地方时（“Agent 公司”“一条街上四家店”），用 `room3d` 模式做成一镜到底：引擎、镜头表写法、缩放和节奏数字、推进电脑屏幕、人从门里走出来、结尾拉远，全在 [modes.md](modes.md) 第 3 节。

- 重点组件放屏幕层（`Overlay.tsx`），不跟镜头走：后面变淡，组件放大到中间
- 术语便签：讲到时贴在物件旁边，再飞到右上角排成一列；推进电脑屏幕和结尾拉远时藏起来
- 只有一两段需要场景感时，不必切模式：在 3D 展板里每块展板摆同一个场景的一部分（例如四种付费方式画成四家店，每家店一块展板），镜头 `fly` 过去就是“走到下一家店”

## 6. 转场

3D 展板和 3D 实景里，**镜头飞 / 走就是转场**，一般不再加全屏转场。2D 平面模式靠全屏转场分段落（登记在 `src/transitions.tsx` 的 `wipes`，示例在 `parts/wipes.tsx`）：

- **少**：只放在大段落开头，一期 3~5 个，每种只用一次
- **和内容有关，有具体形象**：讲工单就让工单落满，讲安全就用钥匙孔收拢。“两束光 + 白圆”这种简单图形被否（“太丑”）；放大撑满后只剩两块色块的形状也不行（盾牌放大后看不出是盾牌）
- **必须真的盖满**，角落不露底
- **别太快**：约 14 帧盖满，停约 4 帧切分镜，17 帧揭开
- **中间不出字**：登记在 `wipes` 表里的转场，盖满时字幕自动隐藏
- **转场前别突然换新画面**又马上盖掉
- **每期新做**，不和以前重复

## 7. 爆点怎么做

重点表里的 3~5 个爆点要敢放：

- 盖章 `stamp` + `Burst` 爆炸星 + 冲击音效
- 聚焦：`FocusDim` 让后面变淡，组件 `Big` 放大到中间
- 整屏变化：大字砸满屏、`mg.Sunburst` 放射光、弹窗刷屏、数字滚动
- 开头冲击卡准关键词：一拳打碎这类效果在说到关键词那一下发生，炸裂但不夸张，只停零点几秒
- 爆点之间至少隔 8 秒

## 8. 克制

- **动效丰富 ≠ 东西多**：不放和字幕重复的贴纸、便签、印章
- **震屏只给真正的冲击**（掉坑、砸墙、关门、东西被改坏），一期 3~4 处；盖章、点按钮不震
- `Burst`、闪光、速度线只在关键点，一期几处
- **不做一直闪的效果**
- 背景互动（地面波纹）约 10 秒最多一次
- 不加多余装饰：尖刺光芒、旁边的小圆点、可有可无的框
