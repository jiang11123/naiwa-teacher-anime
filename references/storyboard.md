# 分镜表

好看的讲解视频，难点不在特效，在“把一句话变成画面”。这一步写在 `storyboard.md` 里，写完再写代码。

## 目录

1. 段落表：选空间、定镜头路线
2. 重点表：哪里华丽、哪里克制
3. 逐句表：每段字幕一个动作
4. 把一句话变成画面（最重要）
5. 素材和 AI 动画放哪
6. 写完自查

---

## 1. 段落表

用第 0 步里用户选定的画面模式（3D 展板 / 2D 平面 / 3D 实景），第一行写上「用的哪种 / 谁定的」。下面的表以 3D 展板为例；3D 实景模式里“空间”一栏写场景里的哪个区，2D 平面模式里写这段用哪个全屏转场开头。

先把稿子切成 4~8 个大段落（钩子、比喻引入、第一部分……总结、结尾），每段选一种空间：

| 空间 | 什么时候用 | 引擎 |
|---|---|---|
| **波点 3D 展板**（默认） | 概念讲解、清单、对比、算账。每个分镜是悬在空中的一块透明展板，镜头在展板之间走 | `World3D` + `timeline.tsx` |
| **3D 实景**（办公室 / 街道） | 主比喻是一个地方（公司、实习生、一条街上几家店），想“一个场景贯穿全片、镜头一路走” | `room3d` 模式（modes.md 第 3 节）；只有一两段需要时，也可以把 `office.tsx` `street.tsx` 的道具摆进展板 |
| **截图窗口** | 教程、讲软件界面、讲真实数据 | `parts/Shot.tsx`（窗口原地换截图用 `keep`） |
| **AI 动画段** | 比喻段落想要更生动的 3D 动画，用户愿意自己去生成 | `src/Ai.tsx`（第 5 节） |

段落之间镜头怎么走（`timeline.tsx` 的进场方式）：

- 段落内：`stay`（镜头不动，旧组件退场、新组件出场）。**别说一两句就换镜头**
- 同一话题换个角度：`slide`（平移）
- 往下深入一层：`push`（推进）
- 大段落之间：`fly`（转身飞到下一个拐角），一期 4~6 次

## 2. 重点表

自己读稿，挑出：

- **爆点** 3~5 个：全片最重要的几句（钩子、反转、结论、最大的坑）。这里用最强的效果：盖章 + 爆炸星、整屏变化、聚焦放大（背景变淡）、镜头推近、可以震一下
- **重音** 每段 1~2 个：段落里的关键词。用 stamp / drop、高亮、数字滚动
- **平句**：其余都是。用轻的出场（rise / pop / fade），一个主体做一个小动作

全片都华丽 = 全片都不华丽。也别反过来全片都收着：爆点处要敢放大、敢盖满。

## 3. 逐句表

每个分镜一张表，**具体到每段字幕**：

```markdown
## 011 订阅-自助餐厅（第 011~020 句）｜空间：展板｜进场：fly｜主体：自助餐厅店面
| 字幕段 | 加什么东西 | 它做什么（动词） | 屏上留的字 | 组件 | 音效 |
|---|---|---|---|---|---|
| 第一种，订阅 | 自助餐厅店面 | 从下浮起，先居中 | 招牌“自助餐厅” | street.Shop + Awning | — |
| 就是办月卡吃自助 | 月卡 | 从天上掉下来，盖在门口 | “月卡” | street.MonthCard，kind=drop | hd_stamp |
| 每个月交一笔固定的钱 | 店面让位到左边，菜单牌从右滑入 | 硬币流进存钱罐 | “每月交一笔固定的钱” | MenuPanel 第 1 行 + icons.jar/coin | — |
```

写的时候对照：

- 每段字幕都写得出**动词**，不是“显示 xxx”
- 分镜**一开场就有主画面**（第一段字幕就出），不让一个标题撑 1~2 秒
- **先居中再让位**：第一个元素先在正中，后面的元素来了，前一组再滑开
- **小组件先出，大组件后出**，不要同时
- 相邻分镜的版式不一样（居中 / 左右对称 / 三栏 / 上下）
- 屏上的字只留关键词、数字、结论，**不复述字幕**
- **每个讲解段都要有插画 / 图标 / 人物在动**，不能是“白板 + 一个字在跳”
- 结尾总结、拉远镜头那几句也要有组件，不能只有场景

## 4. 把一句话变成画面

对每段字幕走一遍：

1. **找动词**：这句话里发生了什么变化？（拿走、撞上、算出来、变便宜、卡住）
2. **找一个日常物件**来演它，优先用这期已经出现过的物件（主比喻里的东西），整期是一个连贯的故事
3. **做完整动作**：起势 → 发生 → 结果，有因果，不是出现再消失
4. **说什么做什么**：说“拿走”就真的飞出屏幕；说“撞”就真的撞上再弹回来

真实例子：

| 台词 | 平庸做法 | 用过的做法 |
|---|---|---|
| 学了大半年 | 写“大半年”三个字 | 台历一页页撕掉，1 月翻到 7 月 |
| 提示词会写，Agent 也会用 | 两个对勾 | 两枚技能徽章盖章拍在小人身上 |
| 一分钱都没赚到 | 红字“0 元” | 钱包砸下、冒灰，徽章变灰 |
| 把盯窗口这件事从你手上拿走 | 窗口淡出 | 窗口一个接一个水平飞出屏幕 |
| 文件太大传不上去 | “超过 25MB”提示 | 大文件撞门弹回，压缩变小后穿过去 |
| 把钥匙拿走 | 贴一只手往旁边拖 | 机械爪下降 → 合拢 → 拎走 |
| 花钱买课不值 | 打叉 | 一拳打碎价签，正好卡在关键词上 |
| 你的一句话在中转站走四步 | 四行文字 | 请求像信封一样飞过去，四步方框逐个亮起，每步下面弹出小字 |
| 按重量称 | “按量计费” | 碗放上秤，指针转到读数，吐出小票 |

**能用真实素材就不自己画**：动手画之前先把用户给的素材翻一遍，看有没有对得上这句的。反过来，讲原因的句子不硬放截图，用动画讲。

## 5. 素材和 AI 动画

**截图 / 录屏**：

- 放在台词真正讲到它的地方；一次只出一张，下一张出来时上一张已经下场
- 先裁掉空白，只留要讲的那块再放大，小字要在手机上看得清
- 要讲的格子用红框圈出来（`Shot` 的 ring / `press.PicRing`）
- 截图不能干停着：截图旁边要有跟着台词弹出的小动画卡；每 2~3 个截图分镜插一段全屏动画

**AI 动画段**（用户自己生成）：

- 分镜表里标出哪几段适合用 AI 动画（主比喻的场景：大厨做菜、店门口排队、东西爆炸），给用户每段的**生成提示词**和插入位置（从哪句到哪句、时长）
- 提示词里写明：纸张手绘风或 3D 卡通、画面里不要有文字、动作和台词的对应
- 用户生成好后用 `scripts/ai.mjs` 接进来；名字、价格这些字用贴纸叠在视频上
- 没生成之前，那几段先用手绘展板做好，AI 动画来了直接盖上去

## 6. 写完自查

- 能说出每个分镜的主角是谁
- 全片只有一个主比喻体系
- 爆点 3~5 个，位置在重点表里写过
- `fly` 4~6 次，都在大段落之间
- 没有连续两个分镜长得一样
- 每段字幕都有动词
