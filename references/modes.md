# 三种画面模式

同一套纸张手绘风，画面空间有三种。一期选一种，在 `src/mode.ts` 里改 `MODE`。三种模式共用同一套组件、字幕、屏幕层（`Overlay.tsx` 的聚焦放大、术语便签）、音效和导出流程。

| 模式 | 看起来是 | 适合 | 不适合 |
|---|---|---|---|
| `board3d` **3D 展板**（默认） | 波点走廊里悬着一块块透明展板，镜头在展板之间推进、平移、转身飞，元素从纵深翻出、轻轻摆动 | 概念讲解、清单、对比、算账；大多数选题 | 主比喻是一个具体地方、想要一镜到底时 |
| `flat2d` **2D 平面** | 一整张波点纸铺满，每个分镜在纸上推拉镜头，大段落之间用有形象的全屏转场 | 截图 / 数据很多的实测、账单拆解、节奏很快的短片；想要干净、信息密的画面 | 想要立体感、空间感时（2D 横向长卷容易显得平） |
| `room3d` **3D 实景** | 一个场景（办公室、街道、厨房）贯穿全片：后墙、地砖、柱子，道具按纵深摆，镜头在里面一路走、俯视、推进电脑屏幕、最后拉远看全景 | 主比喻是一个地方：“Agent 是新来的实习生 → 公司”“四种付费方式 → 一条街上四家店” | 比喻换来换去、内容是并列清单时（一个场景装不下） |

**怎么选**：先看主比喻。主比喻是一个能走进去的地方 → `room3d`；信息密、截图多、要快 → `flat2d`；其余 → `board3d`。拿不准就用 `board3d`，并在分镜表里写一句为什么。用户说了要哪种就用哪种。

三种模式的示例都是同一份 28 秒“AI 幻觉”稿子，改 `MODE` 后跑 `node scripts/check.mjs --out chk/试看` 就能对比。

---

## 1. `board3d` 3D 展板

- 分镜表：`src/timeline.tsx`，每行 `[名字, 展板组件, 第一句 id, 进场方式]`
- 展板组件写在 `src/scenes/`，坐标是 1920×1080，帧是全片帧（示例 `scenes/Demo.tsx`）
- 进场方式 `stay / keep / slide / push / fly`、取景 `framing.ts`、`lift` 分层：见 motion.md 第 4 节、components.md

## 2. `flat2d` 2D 平面

**和 3D 展板共用同一张分镜表、同一批展板组件**：把 `MODE` 改成 `"flat2d"`，展板就平铺在纸上播放（所有 `<A>` 自动变平，不做 3D 翻出和摆动；分镜结束前 8 帧自动退场）。所以同一期可以先按 3D 展板写，再切 2D 看哪个好。

多出来的两样：

**每个分镜的镜头**：分镜表第 5 列，`[全片帧, 缩放, 焦点x, 焦点y]` 的列表。

```ts
["001 开场", Demo.Hook, "001", "stay", [[0, 1, 960, 540], [T("002", 0, 2), 1.06, 1180, 600]]],
```

- 第一帧必须 `[起点, 1, 960, 540]` 居中
- 推近多用 1.04~1.06，最多 1.1；焦点别偏太远；推的方向要有理由（推向刚出现的重点）
- 每个关键帧是“到这一帧时镜头就位”，只在它前 20 帧推过去，其余时间停住
- 不写就是居中不动（只有很轻的呼吸漂移）

**全屏转场**：`src/transitions.tsx` 的 `wipes` 表，`[开始帧, 名字, 组件, 音效]`。

```ts
[startOf("006") - 16, "三级台阶-三招", Stairs, "bl_stairs"],
```

- 开始帧 = 段落第一句的 `startOf − 16`：第 14~18 帧盖满，分镜正好在盖满时切换
- 只放在大段落开头，一期 3~5 个，每种只用一次
- `parts/wipes.tsx` 里有 4 个示例（抽屉、三级台阶、气泡撑满、放大镜）。**每期按内容新做**：和这段讲的东西有关、有具体形象、真的盖满（规则见 motion.md 第 6 节）
- 盖满的帧字幕自动隐藏，音效自动加

2D 模式下，画面变化全靠元素和推拉镜头，更要做到每段字幕一个动作，不然最容易像 PPT。

## 3. `room3d` 3D 实景

整片写在**一个世界**里，不用分镜表。示例：`scenes/DemoRoom.tsx`。

**引擎**（`src/room/`，一般不用改）：

| 文件 | 内容 |
|---|---|
| `room/cam.ts` | 世界常量（地面 `FLOOR = 820`、后墙 `WALL = -700`、贴墙 `ON_WALL`）、镜头关键帧引擎、世界坐标 → 屏幕投影 |
| `room/kit.tsx` | `RoomStage`（房间背景 + 镜头 + 运动模糊）、`P`（世界里的元素，带纵深 z）、`Flat`（平躺在地上的一块）、`Shadow`、`ZWalk`（人沿 x 和 z 走）、`Desk3D`（带桌面厚度的桌子，`DESK_TOP` 是桌面高度）、`Laptop`（屏幕内容放 children，推镜头进屏幕用） |

**写一期的步骤**：

1. **画平面图**：把场景按段落分区，沿 x 排开，每区 1600~2200 宽。比如：大厅 0~2200｜大门 2200~4200｜守则墙 4200~6000。每个区对应稿子的一个段落
2. **摆道具**（世界坐标：x 左右、y 往下、z 朝镜头为正）
   - 贴在后墙上的（窗、门、守则、门牌、大字）：`z = ON_WALL`
   - 站在地上的（桌子、人、柜子）：z 在 -400 ~ 0，越往里越负；人脚底 `y = FLOOR`
   - 空中的提示（贴纸、气泡、盖章）：z 在 -250 ~ 80，别和站着的东西相交
   - 道具用 `parts/office.tsx`（办公室）、`parts/street.tsx`（街道店面）；没有的按同一画法新画
3. **写镜头表** `CAM`：`[开始帧, 缩放, 焦点x, 焦点y, 几帧到位, 转身角度, 焦点z]`

```ts
export const CAM: Key[] = [
  [0, 1.1, 1000, 470, 1, 6],                                   // 开场：第一个区居中
  [T("001", 1, -6), 3.4, 屏幕x, 屏幕y, 16, 0, 屏幕z],          // 推进电脑屏幕
  [T("002", 0, -6), 1.1, 1000, 470, 18, 6],                    // 拉出来
  [T("003", 0, -8), 1.1, 3000, 470, 30, -6],                   // 平移到下一个区
  [T("010", 0, -6), 0.4, 3000, 140, 44, 0],                    // 结尾拉远看全景
];
```

   - 缩放：1.1 看一个区；1.25 推近一点；2.7~3.4 推进电脑屏幕（屏幕占画面一半以上，正对、不俯视）；0.35~0.4 结尾拉远看全景
   - 转身角度 ±6~9：停住时略侧着看才有空间感；平移时引擎会自动顺着方向再转一点（转身感），平移快时自动加横向运动模糊
   - 几帧到位：同区 16~20，换区 26~34，拉远 40~46
   - **镜头提前 6~8 帧开始动**，开口说到时正好到位
   - 一期 6~12 个关键帧。**同一区内不要说一句换一次镜头**
4. **在 `Main.tsx` 里**换成这期的世界：`<RoomStage cam={CAM} pillars={PILLARS}><World /></RoomStage>`（柱子放在分区交界处）
5. **重点组件放屏幕层**：讲到重点时用 `Overlay.tsx` 的 `FOCUS` + `Big` 让后面整个场景变淡、组件放大到中间；术语用 `TermNote` 贴在物件旁再飞到右上角。推进电脑屏幕和结尾拉远时把便签藏起来

**3D 实景里好用的镜头**：

- **推进电脑屏幕看对话**：观众一下子代入（“你看这个对话是不是很眼熟”）。屏幕内容写在 `Laptop` 的 children 里，字号按推近后的大小算（推 3.4 倍时 17 号字 ≈ 58 号）
- **人从门里走出来**：门用 `office.Door` 的 `open`，人用 `ZWalk` 从 `WALL + 90` 走到 z ≈ -200
- **讲到哪里亮哪里**：`office.Spot` 平躺在地上（包在 `Flat` 里）当聚光圈
- **结尾拉远**：整个场景三个区一起出现，把全片收回来

**踩坑**（room/kit.tsx 开头也写了）：

- 不要用 0 尺寸的 div 包一组东西再 `translateZ`，浏览器会把东西排到地板后面。纵深写在每个元素自己身上（`P` 的 `z`）
- 横躺的平面（影子、地贴）不能和站着的东西相交
- 墙、地这种大平面不用 3D 的 DOM（Studio 预览会花），`RoomBg` 已经按镜头投影画成 SVG
- 门不要 `rotateY`（会侧成一条线），俯视角 `rx` 是负数
- 拉远时远处的小字看不清是正常的，结尾那一帧只要大字和整体布局清楚
