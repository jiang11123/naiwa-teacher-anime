# 审片

审美主要靠看。不看图，规则都是空的。

## 1. 抽帧

```bash
node scripts/check.mjs --out chk/r1
```

自动挑：每块展板开头 +12 帧（有没有偏、是不是空纸）、每段字幕中间（主画面出来没有）、每块展板 90% 处（快结束时有没有残留）。联系表每格 640×360，接近手机上的观感——**这个尺寸下看不清的字，就是太小**。

还要专门抽这些帧（`node scripts/check.mjs 帧号 帧号 ...`）：

- 每次 `fly` 飞到一半、飞完那帧
- 东西飞走之后那帧：真的出屏了吗
- 聚焦放大时：有没有压住别的字
- 菜单牌最长那一行：字出框了吗
- 转场盖满那帧（如果有）

改完换一个新目录（`chk/r2`）再抽，前后对比。

整片导出后可以再跑一遍量化检查（需要 ffmpeg）：

```bash
node scripts/review.mjs out/video.mp4 --out review --script scripts/lines.json
```

它会给出：静止超过 3 秒的地方、同样内容停留超过 12 秒的地方（退出码 2）、元素瞬间消失、空屏。

## 2. 每帧问自己

1. 只看这一帧，**主角是谁**？说不出就减东西
2. 不听声音，能猜到这句在讲什么吗？
3. 字有出框、被挡、压字幕、被镜头切掉的吗？
4. 是不是“白板 + 一个字在跳”？
5. 能删掉什么？（总要试着删一个）
6. 和前后两个分镜长得一样吗？
7. 构图是不是内容占 2/3、居中或对称？有没有“左边有图、右边空着”？

## 3. 按时间问

8. 元素是在说到它的那一刻出现的吗？
9. 有没有超过 3 秒什么都没动？
10. 有没有元素一闪而过（出现不到 1.5 秒就走）？
11. 爆点真的够大吗？平句真的够克制吗？
12. 有没有同样的东西在屏上留了 12 秒以上？

**发现问题就改完再抽一遍**，不要把明知有问题的版本交给用户。

## 4. 用户说“丑 / 呆 / 乱”时

先定位是哪一类，再改。用户说好看的部分不要动；修细节，不整体推翻。

| 用户的话 | 通常是 | 改法 |
|---|---|---|
| 呆、像 PPT、单调 | 一个卡片撑一整句；一个人物站着撑一整句 | 每段字幕一个动作；加插画 / 图标 / 人物动作 |
| 乱、太花 | 和字幕重复的贴纸、便签、印章太多；震屏太多 | 运镜留下，重复的贴纸全删；震屏减到 3~4 处 |
| 抓不到重点 | 重点和平句一样大 | 重点用聚焦（背景变淡 + 放大居中） |
| 太干、空 | 只有场景没有组件；元素太小 | 每句都有组件；主体放大 |
| 卡、跳 | 放大后立刻缩回；改 x 导致抽搐；一批批冒出来 | 镜头推到位就停；整组移动用 dx；依次出现要匀速 |
| 瞬间出现、瞬间消失 | 用条件判断直接删掉元素，没有退场 | 用 `out` 让它退场 |
| 东西停太久 | 同一个比喻物件钉在屏上 | 物件轮换，比喻延续 |
| 束手束脚、不敢华丽 | 全片都收着 | 重点表里的爆点放大做 |

## 5. 被否决过的版本

引号里是用户原话。

| 反馈 | 当时的版本 | 学到什么 |
|---|---|---|
| “太呆了……一整个都是动起来，而不是一个卡片在这慢慢讲解” | 一张价格卡慢慢讲 | 整屏要动，每段字幕一个动作 |
| “现在看着有点太乱了，但是有运镜挺好的” | 和字幕重复的贴纸满屏 | 运镜留下，贴纸全删 |
| “震动的效果太多了” | 17 处震屏，盖章也震 | 减到 4 处 |
| “这里的转场换了一个太丑的” | 两束光 + 白圆 | 转场要有具体形象 |
| “又变单调了” | 一个人物站着撑一整句 | 拆成几段动作 |
| “所以你拿走的时候，它还会停留在这里” | 窗口飞了 900px 还在屏上 | 说拿走就飞出屏幕 |
| “刚开始人物是在居中的……运镜的时候再给它运镜到歪” | 开场就偏 | 先居中 |
| “不要白板加一个字在跳” | 讲解段只有一个大字 | 每段都要有插画 / 图标 / 人物动 |
| “转场不能挡住镜头” | 卡片隧道、大按钮转场 | 镜头直接推进 / 穿过去 |
| “抓不到重点” | 重点组件和背景一样 | 背景变淡 + 组件放大居中 |
| “字超出框了” | 便签里长字挤出去 | 按字数算字号 |
| “太干了” | 结尾拉远只有场景 | 每句都要有组件 |
| “音效太多了” | 每个元素都有音 | 只留重点，隔 1.5 秒 |
| “这八分钟有很多感觉都是讲的废话呀” | 8 分钟稿子 | 砍到 3 分钟没丢内容 |
| “你不要给我出现 AI 幻觉啊” | 凭印象写事实 | 查文档，标来源 |

共同点：大多数不是“不够炫”，而是太多、太呆、不干净、不诚实。

## 6. 记下来

每条反馈写进工程的 `taste-log.md`：

```markdown
## 2026-11-12 · 第 2 版预览
- 原话：“……”
- 当时：分镜 011，月卡一直停在门口 17 秒
- 以后：同样内容最多停 12 秒，物件轮换
```

下一期开工前先读它。
