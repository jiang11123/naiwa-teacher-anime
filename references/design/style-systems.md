# 风格

> 判断层：管"哪些能变、哪些不能变、一个元素算不算跑偏"。这套 skill 的外观已经在 `../style.md` 里定死（米黄波点纸、粗墨线、硬投影、四色），这份文件不重选风格。

这个 skill 只做一种外观，但**外观固定不等于每期一样**。真正跟着内容变的是：用哪几个色、谁的色、道具长什么样、转场拿什么做、封面什么构式。这份文件管的就是这些自由度，以及怎么判断一个元素有没有跑出这套语言。

## 已经定死的部分，不要改

动手前先认这几件事，它们不属于"这期可以发挥"的范围：

| 固定项 | 值 | 在哪 |
|---|---|---|
| 底色 | 米黄纸 + 单色浅波点 | `parts/palette.ts` 的 `PAPER` / `DOT` |
| 线和字 | 墨色粗线、硬投影（不用柔和阴影） | `INK` |
| 强调色 | 红（打击点）、黄（注意）、绿（通过）、蓝（说明），不超过这四种 | `RED` `YEL` `GRN` `BLU` |
| 卡片底 | 米白 | `CREAM` |
| 质感 | 线条轻微抖动（`boil`）、纸纹 | `A` 的 `boil` 参数 |
| 动势 | Q 弹（`bouncy`）+ 手绘的轻微不规则 | 见 `../motion.md` |

**这些不是审美标准，是这套风格的身份证。** 想改它们，先问用户；用户没说要改，就一个都别动。

## 这期可以发挥的部分

同样是纸手绘风，两期看起来不该一模一样。自由度在这几处：

1. **配色分配**：四个色都在，但这期用哪个当主强调、哪个少用，跟着内容走。讲风险就多用红，讲步骤就多用蓝
2. **道具**：`src/parts/` 里没有的东西，按同一套画法新画。这是每期最大的差别来源——观众记住的往往是那个具体物件（一张发票、一台服务器、一个秤），不是排版
3. **转场**：`parts/wipes.tsx` 里的是示例，每期按内容新做一个，用这期的主角物件
4. **封面构式**：六种里挑一个，或自己发明（见 `../export-cover.md`）
5. **画面模式**：3D 展板 / 2D 平面 / 3D 实景，第 0 步由用户选

**禁止清单比允许清单更重要。** 风格统一靠"不出现什么"：不要渐变、不要柔和阴影、不要细线框、不要圆角矩形里塞一段话、不要纯色整屏、不要英文小字装饰。

**做实质，不只做减法。** 去掉模板元素之后要有东西补上：主体更大、大字更大、整块颜色、这个题材自己的物件。只减不补，画面会变空，主体小小一个放中间，也算没做好。

## 判断一个元素对不对

不要问"这个元素好不好看"，问：**它和这套风格的其他东西，像不像同一个人做的？**

同一个元素，在不同风格里判决相反：

| 元素 | 手绘风（这套） | 干净 MG | 暗色科技 |
|---|---|---|---|
| 渐变 | 通常不对 | 可以是标志 | 可以 |
| 柔和阴影 | 和硬投影冲突 | 表现轻盈 | 常换成发光 |
| 粗线 | 统一语言 | 突然很重 | 通常不对 |
| 强回弹 | 有弹性 | 太卡通 | 看题材 |
| 线条抖动 | 像手画的 | 像出了问题 | 通常不对 |
| 直角 | 太硬 | 看品牌 | 可以是标志 |
| 深色底 | 通常不对 | 可以 | 就是它 |

**线条抖动、纸纹、波点、硬投影、回弹强度、圆角、深浅底，都只是某种风格的选项，不是审美标准。** 网上的"禁用清单"也一样：有的审美 skill 把小标签和细线当成 AI 味，有的却建议多用它们，说明这些都不是通用规则。只有用户没要求、风格规格也没写、自己又顺手用了，才算"模板脸"。

**风格只换外观和动势。** 观众任务、锚点、关系变图形、字号、看得懂、连贯，都不因风格改变。

## 用户要求换风格时

少见，但要会处理。顺序：用户指定 > 参考视频 > 这套默认。

- **用户指定了某种外观**：照做，即使和你的判断冲突。但先说清"这会偏离 skill 的默认风格，导出后和往期不一致"
- **有参考视频**：先抽帧看，按下面的模板写出规格再动手
- **都没有**：从题材里找三个完全不同的方向，每个一句话，淘汰第一个想到的（那多半是所有视频都会用的默认样式）

规格模板（换风格时填，默认风格下不用填）：

```markdown
# 风格规格：<名字>

**一句话：** 这个风格像什么东西（手账、机场指示牌、杂志内页……）
**底：** 颜色 / 纹理 / 花纹，或者明确写"纯色"
**字：** 字体气质 / 大字怎么处理 / 字幕样式和位置
**线和形：** 线宽 / 形状语言 / 圆角数字 / 是否倾斜 / 投影类型（硬、软、没有）
**颜色和语义：** 色值 → 意思，一般不超过两三种强调色
**动势：** bouncy / snappy / smooth / clean / stepped，选一种（见 motion.md）
**质感：** 纹理、颗粒、线条抖动、光效
**接法：** 分镜之间主要怎么接
**允许：** 这套风格会用的东西
**禁止：** 这套风格不能出现的东西
```

落到代码就是改 `parts/palette.ts` 的色值、`parts/Anim.tsx` 的 `BACK` / `OUT` 缓动曲线、`parts/Anim.tsx` 的 `boil` 强度和硬投影偏移。**改这三处，全片一起变。**

## 风格方向参考

横向参照，不是菜单。用来判断"这套风格在同类里处于什么位置"，以及用户说"想要另一种感觉"时快速定位。

| 方向 | 像什么 | 线和形 | 颜色 | 质感 | 动势 |
|---|---|---|---|---|---|
| 手绘纸张 | 手账、漫画 | 粗线，形状不规则 | 纸色底，几种实色 | 纸纹、线条抖动 | bouncy 或 stepped |
| 干净 MG | 产品发布 | 大圆角，细线框 | 浅底，一种主色 | 光斑、柔和阴影 | smooth，轻回弹 |
| 榜单娱乐 | 综艺字幕 | 贴纸、大字 | 高饱和，档位配色 | 少 | snappy，判决要重 |
| 暗色科技 | 控制台、仪表盘 | 细线，网格 | 深底，一种亮色 | 微光、扫描 | clean 或 snappy |
| 杂志极简 | 杂志内页 | 无框，靠字和留白 | 黑白加一色 | 无 | smooth |
| 复古印刷 | 老海报 | 色块错版 | 少数专色 | 网点、颗粒 | stepped |
| 白板讲解 | 老师板书 | 笔画，边写边出现 | 白底加彩笔 | 笔迹 | 跟着笔画 |
| 等轴图解 | 等距小世界 | 等轴网格 | 明亮分层 | 少 | clean，轻回弹 |
| 数据新闻 | 报纸图表 | 精确，少装饰 | 中性加一种强调 | 无 | clean |
| 像素 | 老游戏 | 方块 | 有限色板 | 像素点 | stepped，帧数少 |

前三种（手绘纸张、干净 MG、榜单娱乐）实际做过成片，其余是通用设计知识，没有用视频验证过。
