# 不同类型视频的打法

> 判断层：管这类视频该按什么顺序讲、重点放在哪。纸手绘风的画法和组件在 `../style.md`、`../components.md`。

每种类型按同样的项目列出。这些是从实际做过的视频里总结的打法，不是模板：内容不合适就改，并说出为什么。

## 1. 产品更新

- **观众任务：** 知道有什么新东西，想去试
- **片长：** 约 25 秒
- **结构：** 产品名和版本 → 更新 1、2、3… → 一句收束价值 → 去哪获取 → 互动
- **锚点：** 稳定的"左边名字、右边真实界面"版式，加更新序号或进度点
- **素材：** 界面截图为主；从截图里裁出结果来当素材
- **节奏：** 每句一个分镜，分镜之间不留空，上一个还没走下一个已经来（重叠约 10 帧）。版式稳定，内容每句都换，用元素变形接下一句
- **转场：** 最多 1 个，给最关键的一句，比如"开源"
- **声音：** 有惊喜感
- **收尾：** 后三个分镜不再放功能截图，改用大字和图形，让情绪落下来
- **常见错误：** 把更新点做成功能列表；每个分镜有明显的切换；结尾还在讲功能

**小公式：** A + B = C。用同一个舞台把几件东西合起来，比单独列出更容易记住。

## 2. 概念讲解

- **观众任务：** 脑子里建立一个模型
- **结构：** 先给官方定义，再讲大白话，之后各段都用同一个比喻往下讲
- **锚点：** 整期一个比喻体系。例如 Agent 讲成公司：实习生、前台、部门。观众不用每段重新理解。延续的是比喻，不是画面上的物体：讲到谁就换成谁，讲完就走
- **轮换：** 比喻讲成一个物体时（工作台、水桶、管道），也要拆成多个画面：推近看局部，切到掉下去的那张纸，再换成一张对比图。不要一直用同一个全景往上添东西
- **素材：** 基本全动画，文档原句可以作证
- **颜色：** 给每个主题分配颜色，全片统一。例如 md 永远是红，json 永远是蓝
- **转场：** 只在段落开头，形象来自内容。讲 json 就大括号合拢，讲 md 就井号条划过
- **常见错误：** 每段换一个比喻；只用比喻不给定义；比喻不准（比喻是拿来解释的，不准就是误导）；把比喻的舞台钉在屏幕上不动

## 3. 软件教程

- **观众任务：** 跟着做成一件事
- **结构：** 要做成什么 → 准备什么 → 第 1 步、第 2 步… → 展示做成的结果
- **锚点：** 同一个窗口贯穿，顶部一直显示当前第几步
- **素材：** 真实录屏或截图为主，隐私打码
- **看清：** 红框圈住要点的地方，镜头推到小字能读（约 2~3 倍）
- **节奏：** 截图不能干停，另一侧放小动画卡片。每 2~3 个截图分镜插一个全屏动画。解释"为什么这样做"的句子改成动画
- **复制：** 需要观众输入的内容放大显示，比如直接可复制的一句话
- **常见错误：** 整片都是截图；鼠标在画面上乱飘；小字看不清；步骤多了之后观众不知道到哪了

## 4. 数据讲解

- **观众任务：** 相信一个结论
- **结构：** 反直觉的现象 → 证据截图，圈出数字 → 一步步算 → 大字结果 → 对比 → 能做什么
- **锚点：** 单位和配色不变。同一个格子全片代表同样的量
- **图形：** 每个数字或观点都配图，图形由关系决定（见 visual-language.md）。常见顺序：截图红框 → 进度格 → 大算式 → 大字结果 → 柱子对比
- **诚实：** 数字写清来源和口径；自己画的图表挂"示意"
- **常见错误：** 只念数字；算式一次全部显示；同一个数字前后单位不同；为了戏剧性夸大比例

## 5. 经验与观点

- **观众任务：** 被说服，或产生共鸣
- **结构：** 开头冲击 → 自己的经历和截图证据 → 几个观点 → 总结
- **开头：** 动作卡准关键词。例如"千万别花钱买课"：拳头蓄力卡在"千万"，砸碎价签卡在"别"。炸，但只持续零点几秒，大叉不要一直停着
- **比喻：** 优先用生活比喻，版本号堆叠、撕台历、钱包冒灰，比抽象图表更能打动人
- **素材：** 真实截图作证，比如评论、帖子
- **人物：** 可以做双人对话，由同学替观众提问。说话要有快有慢，嘴型按真实语速，不能匀速开合
- **常见错误：** 只有人物站着讲；观点没有证据；情绪全程一个强度

## 6. 清单与避坑

- **观众任务：** 带走一组能用的东西
- **结构：** 每项节奏相同：点题 → 为什么坑 → 一句可以直接复制的话 → 怎么做
- **锚点：** 这个四拍节奏本身，加当前第几项
- **变化：** 每项的物件和比喻不同，这样重复不无聊
- **分寸：** 这类最容易越做越乱。一度贴纸、便签、印章满屏，震屏 17 处，最后砍到 4 处，运镜保留，贴纸全删
- **常见错误：** 每项节奏不同，观众抓不到规律；为了不单调往画面上加东西（应该换动作，不是加元素）

## 7. 榜单与锐评

- **观众任务：** 追结果，看得爽
- **结构：** 固定循环：上场 → 讲解 → 判决盖章 → 飞入榜单。一评完立刻上榜，不让人等
- **锚点：** 榜单从头到尾都在，一项项累积。观众能看到进度，会想等到最后
- **版式：** 榜单不动，当前主角放大压在榜单上。上榜后讲解画面可以放大
- **分寸：** 提示类元素 1.3 秒左右退场
- **工程：** 所有内容放一张数据表，改评价只改表
- **风格：** 这种形式常有成熟的参考视频，有参考就跟参考。竖屏要按平台安全区排版，全部居中
- **常见错误：** 讲解时榜单消失；评完不立刻上榜；每一项用不同流程

## 8. 文档或论文解读

- **观众任务：** 不读原文也知道讲了什么，并分得清哪些是原文说的
- **结构：** 这是什么 → 关键发现 → 对你有什么影响 → 哪些还不能确定
- **素材：** 来源标签、原文句子红框、"示意"角标，分清事实边界
- **没有人物时：** 用大字、滚动数字、扫光、弹窗刷屏让整屏动起来
- **常见错误：** 把猜测说成原文；稿子太长（一期曾从 8 分钟砍到 3 分钟，没丢内容）

## 9. 混合类型

很多视频前半段讲、后半段做。分段判断：

- 每段写自己的观众任务，给每段选对应打法
- 字幕和配色语义保持不变，让观众知道还是同一条视频
- 可以换画面模式。一个实际做法：讲概念时用明亮的插画，进入实操步骤时切到深色背景，加"步骤 03/06"的大标题和录屏。观众一看就知道现在是"跟着做"
- 模式切换要少，一条视频两种就够
