# 审片

> 判断层：管"这一版该不该过、问题出在哪一层"。纸手绘风的抽帧命令、组件边界和常见画面异常在 `../review.md`；这份文件的停留率数据可直接套用。

审美靠看。不看图，其他文件里的规则都是空的。

## 审片顺序

从大到小。大问题没解决时，不要先抠细节。

1. **对任务：** 整片看完，观众任务完成了吗？没有就回去改结构，别改动效
2. **对锚点：** 观众知道自己在哪吗？有没有为了"有锚点"，把一个物体钉在屏幕上？
3. **对轮换和分镜：** 东西是不是留太久？每个分镜的主角清楚吗？版式有没有连续重复？
4. **对帧：** 出界、叠字、残留、切字
5. **对时间：** 东西是不是说到才出现，有没有停太久或一闪而过
6. **对手感：** 动作是否符合选定的动势，分镜之间连不连贯（见 motion.md 第 4、5 节）
7. **对风格：** 是真的做到了风格规格的每一项，还是只抄了颜色？

## 怎么看

用工程里的 `scripts/review.mjs` 可以一次生成联系表和逐帧条，列出长时间没变化的片段，并算出停留率（模板自带，ffmpeg 不在 PATH 时设 `FFMPEG`）。

**先看停留率。** 它统计字幕上方的内容，过几秒后还有多少没变。讲解类的参考线是 3 秒后不超过约 50%，10 秒后不超过约 30%。

| 视频（全片实测，同一算法） | 3 秒后没变 | 10 秒后没变 | 同样内容留 12 秒以上 |
|---|---:|---:|---|
| 一位创作者的 5 条成片 | 20%~39% | 17%~28% | 3 处，5 条共约 23 分钟 |
| 一个没用 skill 的模型，52 秒 | 59% | 33% | 1 处，17 秒 |
| 一张桌子贯穿全片的版本，52 秒 | 81% | 64% | 1 处，31.5 秒 |

**停留上限是 12 秒。** 内容过 6 秒后还有七成没变，这样连续超过 12 秒，脚本判不通过，退出码为 2。例外的条件在 `README.md` 第 4 步，符合的用 `--keep 开始秒-结束秒` 标出来，交付时说明。

| 视频（同一算法） | 最长停留 | 结果 |
|---|---:|---|
| 一张纸留在画面上的 29 秒测试片 | 17 秒 | 不通过，简报的理由是"它是舞台，一直在变形" |
| 一条 31 秒测试片 | 不足 6 秒 | 通过 |
| 一位创作者的 5 分钟成片 | 11 秒 | 通过 |
| 同一位创作者的另一条 5 分钟成片 | 16.5 秒 | 2 段超过，都是清单留着、旁边一直换主体，属于例外 |

- 这个脚本分不清例外和借口：框架留着和一张纸留着，它算出来一样。例外要逐段对照第 4 步的条件
- 不超过 12 秒不代表轮换够好，还要看停留率和联系表
- 这个数只能发现"留太久"，不能证明好看。太低也可能是在乱闪，要配合联系表看
- 榜单、教程窗口本来就要留着，数字高不算错，只看框架里的内容有没有换
- 参考线来自一位创作者的成片，换一种类型或风格可以调，但要说得出理由

**再看瞬间消失和空屏。** 脚本会列出帧号：上一帧还稳稳摆着、这一帧大块内容就没了，算瞬间消失；字幕上方连续几帧几乎什么都没有，算空屏。逐个去看，原因和改法见 motion.md 第 4 节。

| 视频（同一算法） | 瞬间消失（每分钟） | 空屏 |
|---|---:|---:|
| 一位创作者的 2 条成片 | 1~2 次 | 0~16 帧，全片 |
| 用户说"瞬间出现、瞬间结束"的 30 秒测试片 | 10.2 次 | 21 帧 |
| 同一条，分镜改用 `Beat` 和转场 | 0 次 | 0 帧 |

- 这个数查得出凭空消失，查不出"换段落时什么都没有"。另一条被用户说转场奇怪的片子，每分钟只有 1.9 次，问题在清屏和没有转场，要靠逐帧看
- 这个数是 0 不代表好看

**给了字幕时间表，再看一句一变化。** 加上 `--script script.json`，脚本会列出开口 1 秒后才有变化、或者整句都没变的句子。线条抖动不算变化。

| 视频（同一算法） | 开口 1 秒内有变化 |
|---|---:|
| 一位创作者的 2 条成片 | 140 句中 138 句，145 句中 143 句 |
| 两条 30 秒测试片 | 12 句中 11 句，12 句中 12 句 |

- 这只是底线：测试片和成片的数字差不多，画面上的差距它查不出来，因为它只看有没有变，不看变得好不好
- 列出来的句子逐条看。开头打字、刻意停一下，都可以是对的

**再看爆点。** 脚本统计半秒内画面变了多少。全片没有一处超过一半，判不通过；`--peaks 12.3,40` 传入重点表里的爆点，够不到一半也判不通过；两次接近整屏的变化隔不到 8 秒会提示，连着炸就没有对比了。

| 视频（同一算法） | 最大变化 | 变化过半 | 接近整屏 |
|---|---:|---:|---:|
| 一位创作者的 2 条 5 分钟成片 | 98%、100% | 各 20 处 | 2 处、4 处 |
| 一条 31 秒测试片 | 100% | 2 处 | 2 处 |
| 一条 29 秒测试片（转场 0 个、震屏 0 处） | 43% | 0 处 | 0 处 |

- 这个数只看大小，查不出好不好看。上面那条 31 秒测试片数字不差，但盖满时是一块纯色加一个小物件；成片盖满时是同心圆、彩色格、警戒胶带。要去看盖满那几帧
- 它也查不出爆点是不是放在了对的句子上，要拿重点表对

**再看联系表。** 全片均匀抽几十帧拼成一张，每格约 480×270（竖屏每格约 240 宽），接近手机观感。这个尺寸下看不清的字，就算太小。联系表还能看出整片的单调和跳脱：连续几格长得一样，或某格和全片不搭，一眼就能发现。

**再抽关键帧：**

- 每个分镜第一帧：有没有偏，是不是空的
- 第一段字幕中间：主画面出来了吗
- 推近后：有没有切字
- 步骤切换那帧：有没有上一步的残留
- 转场盖满那帧：盖全了吗
- 东西飞走之后：真的出屏了吗

**每帧问：**

1. 主角是谁？
2. 关掉声音，能猜到这句讲什么吗？
3. 字有没有出框、被挡、压字幕？
4. 能删掉什么？总要试着删一个
5. 这是这期才有的画面，还是什么视频都能用？不用这个 skill 也能做出来吗？

**按时间问：**

6. 这个元素是在说到它时出现的吗？
7. 有没有超过 3 秒什么都没动？（教程读截图除外，但要有小动画）
8. 有没有元素一闪而过？
9. 联系表里是不是连续好几格都是同一个构图？只有小东西在变也算
10. 这个主体的离开时间是什么时候？答不上来，它多半留太久了
11. 联系表里除了卡片，还有别的吗？背景有变化吗？物件是不是全是矩形？（见 effects.md）
12. 把联系表缩小并转成灰度，每格能一眼找到主体吗？背景、容器、主体分得开吗？
13. 配色和形状说得出是什么感觉吗？和这期的内容、风格规格对得上吗？
14. 空白是在衬托主体，还是东西太小？有没有容器压过内容，或者空容器单独占一拍？
15. 每个切点，东西是走掉的，还是突然没了？下一拍是接上来的，还是清空画面再来？
16. 换大段落时有转场吗？转场上是这期的东西，还是一块纯色？
17. 随便停一格，说得出画面上的东西是什么吗？还是只有线框、卡片和小字？
18. 屏上的字是不是字幕的压缩？有没有复述整句，或者放了观众用不上的术语和英文？
19. 全片有没有情绪起伏？谁在替观众感受，或者靠什么传达？
20. 开头的东西后面回来了吗？回来时变样了吗？
21. 重点表里的爆点，看到时会不会愣一下？有没有想截图的一格？小到可以忽略，就是没做
22. 夸张的地方是最重要的句子吗？爆点前后是不是安静的？处处都热闹也不合格

发现问题改完再抽一遍，不要把明知有问题的版本交给用户。**没有条件抽帧时，要告诉用户画面没有看过。**

## 判断是"太多"还是"太呆"

这是最常见的两种问题，修法相反。

| 症状 | 判断 | 修法 |
|---|---|---|
| 同时有很多东西，不知道看哪 | 太多 | 删元素，留动作和运镜 |
| 只有一张卡片摆着，慢慢讲 | 太呆 | 拆成几段动作，不是加贴纸 |
| 每个分镜看起来都一样 | 太呆 | 换版式，换关系图形 |
| 强效果很多，但记不住 | 太多 | 只保留最关键的几处 |
| 空白很多，主体很小 | 太散 | 放大主体，不是加东西 |
| 同一个东西摆在中间很久，只有上面的小件在变 | 久留 | 拆成几个画面，推近、换物、让它离开 |
| 组件都在弹，但背景一块白，物件全是矩形 | 太素 | 按 effects.md 四层补：背景、物件、动作结果、字 |
| 动效不错，但整屏发闷，形状生硬，主体被大容器压小 | 视觉没有决定 | 拉开明暗层次，重选配色比例和形状语言，让内容压过容器 |

**"动效丰富"和"东西多"是两回事。** 丰富指一个主体在做有意义的动作。

## 真实被否决的版本

引号里是创作者的原话。

| 反馈 | 当时的版本 | 学到什么 |
|---|---|---|
| "太呆了……感觉一整个都是动起来，而不是一个卡片在这慢慢讲解" | 一张价格卡慢慢讲 | 每段字幕一个动作 |
| "现在看着有点太乱了，但是有运镜挺好的" | 和字幕重复的贴纸满屏 | 运镜留下，贴纸全删 |
| "震动的效果太多了……看着就有点奇怪" | 17 处震屏，盖章也震 | 减到 4 处 |
| "这里的转场换了一个太丑的" | 两束光加白圆 | 转场要有具体形象 |
| "又变单调了" | 一个人物站着撑一整句 | 拆成几段动作 |
| "所以你拿走的时候，它还会停留在这里" | 窗口飞了 900 像素还在屏幕上 | 说拿走就要出屏，抽帧确认 |
| "这个盾牌转场这里也很奇怪" | 盾牌放大后只剩两块蓝 | 换成轮廓明确的钥匙孔 |
| "刚开始人物是在居中的……运镜的时候再给它运镜到歪" | 开场就偏 | 先居中 |
| "字太多了，让人看不到重点" | 封面五六块文字 | 封面只留三块字 |
| "空白又留的有点多了" | 封面元素太小 | 放大铺满 |
| "这八分钟有很多感觉都是讲的废话呀" | 8 分钟稿子 | 砍到 3 分钟，没丢内容 |
| "你不要给我出现 AI 幻觉啊" | 凭印象写事实 | 查文档，标明来源 |
| "说的太快了……不要固定是一样子" | 嘴型匀速开合 | 按逐字时间，有快有慢 |
| "动效是真的差，他们不会 Q 弹什么的。而且也不连贯" | 想法不错，但东西硬邦邦地落下，前后画面接不上 | 动势写成数字，用现成动效工具，上一个走、下一个紧接着来 |
| "那个桌子会在那里待很久很久都不动……它基本上一个元素，它是过一下就消失掉了" | 为了"不清屏"和"有锚点"，同一张桌子留了约 33 秒 | 延续比喻，不延续物体；主体要有离开时间 |
| "假如它的动效是放大的，然后它又会立马又回过去，这样子就会感觉很卡" | 每个分镜的镜头都从 1 倍重新推，切点上画面先缩回去 | 跨分镜时镜头接着走，每个切点逐帧查 |
| "它有很多东西都是直角的，直角就看着比较生硬" | 风格规格写了"纸是直角"，还禁止圆角卡片；画面是深色切割垫 | 这不是说直角一定不好，而是这里的直角只是照抄实物，和轻松的讲解不搭。形状要主动选，配这期的气质 |
| "它这个动效 Q 弹的效果有点奇怪" | 每次落地都有一帧压成 1.22 × 0.70，下一帧弹回，连整层画面也这样；弹出拆成几段关键帧，顶点停几帧才回落 | 回弹用一条连续曲线，压扁只给少数东西；配方要从真实成片的代码里取 |

| "它们每个动效出现和结束的时候，经常是瞬间的出现和瞬间的结束……它们转场也没有东西" | 代码写 `frame < N` 把整组删掉，退场没播就没了，再空几帧才出新内容；换段落时什么都没有 | 用 `Beat` 管进出，两拍之间不留空；大段落用内容相关的转场 |

| （审片时发现）一条片子 6 个分镜全部整组飞向左边，新章节的大字压在没走完的卡片上 | `Beat` 默认飞出 1400 像素，模型照默认用了；成片里的退场其实只挪约 110 像素再淡出 | 默认改成轻退场，飞走要专门写 `far`。工具的默认值就是模型的审美 |

| （审片时发现）一张清单纸留了 17 秒，简报写"转场 0 个" | 简报的理由是"它是舞台，且每一段都在变形"。规则只写"要有理由"，模型就写了一个理由 | 上限改成脚本判定，例外只留两种，"一直在变"不算例外 |

| "它不敢放开去做动画，不敢使用华丽的特效……要有个度，不能一直很夸张" | 规则和工具默认值都在往小里收，简报写"不做震屏、碎片、粒子爆炸"，全片没有一处让人记住 | 先从文案里找重点，重点句放开做，其余收着。度靠对比，不靠压低所有效果 |

共同点：多数是太多、太呆、不干净、不诚实，所以这些都要避开。但上面最后一条说明，全都收着也会被否。

## 处理用户反馈

- 用户的反馈优先于这个 skill 的所有规则
- 问清楚是哪里不对，修那里，不要整体推翻。只有用户要重做，才整个换掉，那时也不要在旧样子上打补丁
- 用户说好的部分保留。例如上面的"太乱了，但是有运镜挺好的"：只删贴纸，不动运镜
- 用户的评价通常是感受，自己把它翻译成原因。说"呆"常指静止太久，说"乱"常指主角不清楚
- 把反馈和原因记进项目的 `taste-log.md`，下一期先读。这个文件比任何通用规则更接近这位用户的审美

## 这份规则也有边界

这些规则主要来自一位创作者的视频和反馈。换一位创作者，具体的口味可能不同。可信度从高到低：

1. **取舍顺序、看图审片、一帧一个主角、诚实：** 基本通用
2. **观众任务决定结构：** 通用的方法，具体打法要按账号调整
3. **字号、帧数、音量：** 经验值，按手机讲解视频得出，可以调
4. **动势配方：** 起点值，看成片再调
5. **从其他 skill 借鉴的内容：** 还没验证，取舍见 sources.md
