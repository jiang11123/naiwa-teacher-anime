# 画面语言

> 判断层：管"关系怎么变图形、句子怎么变动作"，不依赖具体风格。纸手绘风的颜色、线宽、字、构图参数在 `../style.md`。

不依赖具体风格的画面规则。数字按 1920×1080 或 1080×1920、30fps 给出，其他分辨率按比例换算。

## 1. 把关系变成图形

文字卡是最后的选择。先问这句话里是哪种关系：

| 关系 | 图形 | 例子 |
|---|---|---|
| 定义 | 等式、分数 | 缓存命中率 = 存好的 ÷ 发过去的全部 |
| 部分占整体 | 一排格子、进度条 | 70 万 = 0.7 个 100 万：十格涂七格 |
| 累积、重复 | 逐层加长的阶梯 | 每发一条，前面的内容再计一次费 |
| 范围、阈值 | 分区的长条 | 每个对话控制在 15 万到 35 万 token：长条上涂出这一段 |
| 对比 | 等大的两块并排 | 适合 / 不适合 |
| 先后 | 步骤点、管道、箭头 | 第 1 步到第 4 步 |
| 因果 | 一个东西撞上另一个，产生结果 | 大文件撞门被弹回，压缩后穿过去 |
| 循环 | 首尾相接的箭头 | 总结错了 → 存进去 → 之后当成事实 |
| 包含 | 容器和里面的东西 | 文件夹里装着知识 |
| 连接 | 中心和几条线 | 几个工具接到同一个知识库 |
| 位置、相似 | 坐标空间 | 意思相近的词坐标也近 |
| 变化 | 同一个物体变形 | 卡片直接变成下一句的图标 |
| 评级 | 榜单、盖章 | 夯、顶级、NPC、拉完了 |
| 证据 | 真实截图和红框 | 原文这句话圈出来 |

如果一句话里没有关系也没有动作，先问这句是否有必要。

同一期里，同一种关系用同一种图形，观众会越看越快。不同关系不要都用一种图形。

## 2. 把句子变成动作

逐段字幕走一遍：

1. **找动词。** 这句话里发生了什么变化？（拿走、撞上、算出来、变便宜）
2. **找物件。** 用日常东西演。优先用这期已经出现过的物件，整期连成一个故事。物件可以再次登场，但不用一直留在屏幕上
3. **做完整因果。** 起势 → 发生 → 结果。不是元素出现再消失
4. **说什么做什么。** 说"拿走"就飞出屏幕，说"撞"就真的撞到再弹回

| 台词 | 平庸做法 | 用过的做法 |
|---|---|---|
| 学了大半年 | 写"大半年" | 台历一页页撕掉，1 月翻到 7 月 |
| 提示词会写，Agent 也会用 | 两个对勾 | 两枚徽章盖章拍在小人身上 |
| 一分钱都没赚到 | 红字"0 元" | 钱包砸下、冒灰，徽章变灰 |
| 把盯窗口这件事从你手上拿走 | 窗口淡出 | 窗口一个接一个水平飞出屏幕 |
| 为什么要先验证账号 | 一段文字 | 机器人撞立柱弹回，盖章后才放行 |
| 把钥匙拿走 | 一只手往旁边拖 | 机械爪下降 → 合拢 → 拎走 |
| 花钱买课不值 | 打叉 | 一拳打碎价签，卡在关键词上 |
| 工具更新太快 | "更新很快" | 课本 v1.0 旁边工具卡一路更新到 v6.0 |

物件要一眼认得出。画不好就换一个物件，或者不要。

## 3. 构图

- **一帧一个主角**，再加一两个辅助。主角高度不到可用高度一半时，先放大，不要加东西填空
- **版式来自内容关系。** 讲解默认居中、上下排；真在做对比就等大并排；"名字加证据"可以左右排。不要左边标题、右边要点列表
- **先居中，再让位。** 开场第一帧稳定，后面元素要进来时前一组才滑开，镜头也之后才动。开场就偏看起来像做错了
- **铺满不贴边，** 保留安全边距和字幕区
- **并排的东西**等宽、等高、等间距
- **相邻分镜换版式。** 除非这个重复本身是锚点（榜单、教程窗口）
- **留白要有意。** 任何风格都可以留很多白，但要看得出是安排过的：主体够强，空白在衬托它。东西挤在一角、其余随便空着，不算留白
- **容器不能压过内容。** 舞台、边框、窗口这类容器要帮内容，不能占了大部分面积，里面却只有几个小东西。这时放大内容，或者去掉容器
- **空容器不单独占一拍，** 除非"空"就是这一拍要讲的事
- **不放没意义的固定装饰：** 页码、线圈、章节角标。观众以为它们有意义。有用的进度提示不算
- **人物要有事做，也要有反应。** 事情落到它身上时它会变脸、会被撞。讲完就退场，不加小号装饰角色

**横屏：** 内容约 y 40~930，字幕约 960~1060。

**竖屏：** 纵向分层：上面是标题或步骤，中间是主体，下面是人物和字幕。约 y 80~1550 放内容，字幕约 1580。发短视频平台时避开顶部状态栏、右侧按钮、底部文案区。竖屏宽度有限，优先放大主体，不要左右排多列小东西。

## 4. 字

按手机算（1080 高的横屏）：

| 用途 | 字号 |
|---|---|
| 大字 | 110~190 |
| 胶囊标题 | 60~80 |
| 卡片文字 | 56~90 |
| 字幕 | 56（竖屏约 62） |
| 来源标签等小字 | 不小于 36 |

- 画面字不复述字幕，只留关键词、数字、结论
- 一屏一个视觉最大的字。全都大，就等于没有大
- 字不能出框。中文实际比估算宽，容器要留余量
- 英文词不要被拆开换行
- 字幕每段约 20 字以内，不到 0.6 秒的短段并入下一段
- 爆点词要有动作：跳起、盖章、放大。只换文字内容不算动画

## 5. 颜色和形状

具体值看风格规格。用法通用：

- **语义固定：** 红给打击点和警告，绿给通过，等等。到处都红就没有重点了
- **大面积用浅色，小面积用饱和色**
- **一帧里饱和色最多两种**
- **背景只有一个声部。** 背景花纹是一种颜色、一种形状，不抢主画面
- **主题色可以绑定内容：** 这个概念全片用这个颜色
- **对比度按手机算：** 手机屏幕亮度低、环境亮，弱对比的灰字看不见
- **语义对不等于好看：** 语义只决定红给谁。配色还要自己成立：先定一个主导色，再定辅助色和少量强调色，按大约 6:3:1 分配。这个比例是常见起点，不是定律
- **明暗分层：** 不管底是浅是深，背景、容器、主体的明暗都要拉开，主体最跳。转成灰度看一帧，一眼找不到主体，就是层次没拉开
- **明度和饱和度要有取舍：** 深底要靠很亮的主体或发光撑住，浅底要靠深色线条或实色撑住。整屏都是中等明度、中等饱和时最容易发闷
- **颜色的性格要配内容：** 高饱和活泼，低饱和稳重，黑白加一色克制。选低饱和或暗色时，要用对比和质感把画面补回来

### 形状

形状和颜色一样带情绪。它是风格的一部分，要主动选，不要默认，也不要照抄实物。

| 形状语言 | 给人的感觉 | 常见于 |
|---|---|---|
| 大圆角、圆形、胶囊 | 亲切、轻松 | 大众讲解、可爱插画、产品发布 |
| 不规则的手绘边 | 手作、有人味 | 手账、漫画 |
| 小圆角 | 冷静、专业 | 商务、产品界面 |
| 直角、尖角 | 硬朗、精确、有力 | 杂志、报纸、数据新闻、暗色科技 |
| 方块 | 复古、游戏感 | 像素 |

- **选了就要做到位。** 圆就圆得明显，方就方得干脆。缩到手机上，圆角小到看不出，又不是有意的直角，就是没有决定
- **形状要配气质。** 直角配上轻松的语气和呆板的版式，就只剩生硬。如果想要硬朗，要配合精确的排版和有力的字
- **形状语言全片一致，** 具体物件的轮廓除外
- **矩形不是唯一的选择。** 除非这个风格的重点就是网格和方块，否则要用具体物件的轮廓和其他形状打破矩形

## 6. 动效

手感的数字、配方和连贯规则都在 [motion.md](motion.md)，这里只讲入场怎么选。

**按分量选入场。** 轻的东西淡入上浮，有重量的落下，结论盖章。全部一种入场，就没有轻重，像幻灯片。具体幅度由这期的动势决定。

| 分量 | 入场 | 用在 |
|---|---|---|
| 轻 | 淡入、上浮 | 辅助信息 |
| 中 | 弹出、侧滑 | 卡片、道具 |
| 重 | 落地 | 有重量的东西 |
| 最重 | 盖章 | 结论、判决 |
| 特殊 | 翻转 | 揭晓答案 |

- **切走前至少停留 1.5 秒，** 撑不住就删掉这块
- **主体约 3~6 秒就要走、被替换、移位或变形。** 在它上面陆续添小件不算换，呼吸也不算
- **分步讲解时，上一步的所有元素都退。** 残留的箭头很显眼
- **效果有开始和结束。** 一直闪、一直转会抢注意力

## 7. 运镜

- 第一帧居中，镜头之后才动
- 推到位就停，不要整段慢慢漂
- 不走回头路：同一个主体跨分镜时，镜头接着上一个分镜走，不退回去再推
- 推的方向有理由：讲到哪里，推向哪里
- 普通推近约 1.04~1.06，看清截图小字才推到 2~3 倍
- 推近后检查有没有切字、露边
- 大段最后一个分镜，动作要在结束前做完，尾巴会被转场盖住

## 8. 转场

- **形象来自这期内容。** 讲工单就工单落满，讲安全就钥匙孔收拢。一张放进别的视频也成立的转场，就不够好
- **轮廓要明确。** 放大撑满后还能认出是什么，不能只剩两块色块
- **真的盖满，** 角落不露底。盖满时不出字，字幕也隐藏
- **别太快：** 约 14 帧盖满，停 4 帧切分镜，17 帧揭开
- **盖满时上面要有东西。** 纯色停着就是一块闪屏。放这期的物件，或者让物件本身铺满，或者铺满图案（格子、同心圆、警戒胶带）。纯色上放一个小物件，也还是一块纯色
- **每种只用一次，每期新做**
- **用 `Wipes` 起步，** 从 `src/transitions.tsx` 的转场表里加一条，把 `parts/wipes.tsx` 的示例换成这期的东西。只换颜色不换物件，就是一张什么视频都能用的转场

## 9. 音效

- 只做点缀：配音音量 1，音效 0.05~0.13，冲击最多 0.18
- 不是每个元素都要响，同一时刻只响一个
- 同一个声音不连着重复。列表逐条出现时用音阶上行，把重复变成旋律
- 声音和动作的分量一致：落地低沉，盖章有力，飞过带风声

## 10. 通用模板脸

下面这些不是错在元素本身，而是错在**没有经过判断**。用户要求或风格规格写了就可以用，只是顺手用就不行：

- 紫蓝渐变加深色背景的"科技风"
- 所有东西都是圆角卡片加柔和阴影。这里的问题是千篇一律，不是圆角本身，不要因此把圆角列为禁止
- 每张卡片左上角一个 emoji 图标
- 左边大标题，右边三条要点
- 所有元素淡入上移，每个时长一样
- 字号在电脑屏幕上刚好，手机上看不见
- 满屏粒子和光效，但说不出和内容的关系
- 用 emoji 代替具体产品，有真实 logo 的要用 logo，没有就写文字牌
