# 组件之外的效果

> 判断层：管"要不要加、加几个、加到哪一层"。纸手绘风的效果参数和现成组件在 `../style.md`、`../motion.md`、`../components.md`，以及工程里的 `src/parts/fx.tsx`。

只有卡片在弹，画面还是素的。好看的讲解视频里，组件之外还有很多东西在发生：背景在变，东西落下时冒烟，打碎时有碎片，结论出来时有闪光。

测试里有一条片子，组件的 Q 弹已经做对了，创作者还是嫌单调："都是一个白布，然后后面的组件在那里 Q 弹而已。"

这份文件在写分镜时读。**分寸的规矩不变：** 每个效果都要绑定一个动作或关键词，有开始有结束，做完就走。

## 1. 先查四层有没有落空

| 层 | 问的问题 | 做得素的样子 | 可以怎么做 |
|---|---|---|---|
| 背景 | 背景有没有自己的东西？换段落时变不变？ | 一块纯色从头用到尾 | 纹理、暗角、漂浮小图形、放射光、换段落时背景换色 |
| 物件 | 这句话里的东西长什么样？ | 全是矩形和线条 | 把它画出来：讲代购就是店铺和货箱，讲价格就是价签 |
| 动作结果 | 动作发生后留下了什么？ | 卡片落下，什么也没发生 | 冲击线、烟尘、碎片、旁边的东西被撞开 |
| 字 | 爆点词有没有自己的动作？ | 字幕念完就结束，画面上没有大字 | 逐字弹出、滚动数字、盖章、下划线画出来 |

四层都要过一遍。全片只靠一层撑场面，就会单调。

**物件这一层最容易被忽略。** 全片都是矩形条时，加再多特效也还是素的。先想这句话里的具体东西，只有抽象概念才用格子和线条。这个 skill 的物件库在 `assets/template/src/parts/props.tsx`、`props2.tsx`、`props3.tsx`、`props6.tsx`，有现成的文档、文件夹、店铺、服务器、人物、机器人等，外观跟着纸手绘风参数走；没有的就照同一套画法新画一个。

## 2. 效果怎么选

从内容里的动作出发，不要先挑一个好看的特效：

| 内容里发生了什么 | 可以用 | 分量 |
|---|---|---|
| 东西落地、放下 | 烟尘，旁边的东西晃一下 | 轻 |
| 重点要看这里 | 画圈、画下划线、箭头画出来 | 轻 |
| 出现一个好结果 | 闪光、扫光 | 轻 |
| 数字变化 | 数字滚动，到位时弹一下 | 轻 |
| 东西撞上、卡在关键词上 | 冲击线、冲击环 | 中 |
| 东西被抽走、冲过去 | 速度线，加运动轨迹 | 中 |
| 爆点词、标题 | 逐字弹出，配冲击线 | 中 |
| 换大段落 | 背景换色、内容相关的转场 | 中 |
| 打碎、撕掉、撞坏 | 碎片，碎片用这个东西本身的颜色 | 重 |
| 真正的大冲击 | 震屏，配爆点 | 重 |
| 开场或高潮要有气势 | 放射光背景转起来 | 重 |

**风格决定长相和多少：** 手绘风的冲击线是粗墨线，干净 MG 是细线和圆点，高级感的片子用一道扫光和一层缓慢的背景变化就够。严肃内容少用碎片和爆点。颜色和线宽都从风格规格里来。

## 3. 用多少

下面的数字是起点，按 1 分钟的讲解估算，来自一位创作者的成片和反馈，看成片再调：

- **种类：** 一条片子至少用到 4~6 种不同效果，相邻两次不重复
- **频率：** 平均每 5~8 秒有一次组件之外的效果，轻效果占大多数
- **重效果：** 碎片、震屏、放射光加起来，一分钟 2~3 处
- **爆点：** 数量和位置由 `README.md` 第 3 步的重点表决定。这里的数字是平句和重音用的，爆点要大得多，不要拿小效果凑数
- **时长：** 大多在 1 秒以内做完，爆点 1~2 秒。背景层可以一直在，但要淡到不抢戏

写进设计简报的效果表，每一行写清楚：第几秒、哪个效果、绑定哪个动作。

## 4. 怎么判断是丰富还是乱

丰富和东西多是两回事。创作者否决过满屏贴纸（"有点太乱了"）、17 处震屏（"看着就有点奇怪"），也否决过这条全是组件的（"太单调"）。分界线是：

- **绑在动作上的是丰富：** 东西落地时冒一下烟，马上散了
- **一直挂着的是乱：** 贴纸、便签、印章留在画面上，还和字幕说同一件事
- **一直闪、一直转的是乱：** 背景层除外，且要淡
- **同时炸好几处的是乱：** 同一时刻只有一个主效果

拿不准时，关掉效果看一遍这个动作。如果没有它动作也一样清楚、一样有劲，就删掉。这一条只用于平句和重音。爆点的作用是让观众记住这句，不是让动作更清楚，不要用这条把它删掉。

**太保守也是错。** 全片效果都很小、处处都合理，但看完什么都记不住，同样不合格。重点句上做小了，就放大到整屏；放大后觉得过了，再往回收，比一开始不敢做强。

**放效果时要看图：** 冲击线应该落在空白处，穿过文字或一堆卡片就只剩乱线。主体周围没地方时，换成环、烟尘或旁边物体的跟随。

## 5. 现成组件

纸手绘风的实现全在工程里，直接用，不要重写一遍：

| 想要的效果 | 用哪个 | 放在 |
|---|---|---|
| 冲击线、爆炸星 | `parts/fx.tsx` 的 `Burst` | 内容上面 |
| 四周速度线 | `SpeedLines` | 内容上面 |
| 落地烟尘 | `Dust` | 内容上面 |
| 逐字砸出的大字 | `Chars` | 内容层 |
| 数字滚动 | `Count` | 内容层 |
| 东西飞出去 | `Fly`（带弧线、旋转、消失时机） | 内容层 |
| 整屏镜头推进 + 震 | `Cam` 的 `shakes` | 包住整层 |
| 放射光背景 | `parts/mg.tsx` 的 `Sunburst` | 内容下面 |
| 抖一抖 / 鼓一下 | `Wobble` / `usePulse` | 包住元素 |
| 前一层变淡、主体放大 | `parts/focus.tsx` 的 `FocusDim` + `Big` | 内容层 |
| 整屏换场 | `src/transitions.tsx` 的 `Wipes` | 分镜之间 |

颜色一律从 `parts/palette.ts` 取（`INK` 墨、`YEL` 注意、`RED` 打击点、`GRN` 通过、`BLU` 说明、`CREAM` 卡片底），**不要临时写色值**，否则换不了一套。

这些只是起点。题材有更贴切的效果就自己做，比如讲水就做水花，讲纸就做纸屑。题材里长出来的效果，比通用特效好。
