## 1. 取舍顺序

两条规则打架时，排在前面的赢：

1. **看得懂**：观众在手机上、不暂停，也能明白这句在说什么
2. **干净**：不出界、不叠字、不遮挡、不残留，主体清楚
3. **节奏对**：东西在说到它的那一刻出现，停够时间让人看清
4. **有意思**：比喻准、动作有戏、有一两个让人想截图的点
5. **华丽**：光效、粒子、爆炸

“动效丰富”和“东西多”是两回事。丰富是一个主体在做有意义的动作。

## 2. 弱模型的默认坏习惯

| 坏习惯 | 改成 |
|---|---|
| 左边标题 + 右边要点列表 | 居中、一次一个主体，或对称两栏 |
| 一张卡片摆一整句话 | 每段字幕一个动作 |
| 所有元素同一种淡入 | 按分量选 pop / drop / stamp / rise |
| 线性、匀速 | 回弹和缓动 |
| 字幕内容再贴一遍在画面上 | 画面演动作，只留关键词 |
| 字号 24~36 | 卡片字 ≥ 48，大字 110~240 |
| 渐变、毛玻璃、柔和阴影、细线 | 粗墨线、硬投影、实色 |
| emoji 代替产品 logo | 真实 logo，没有就写文字牌 |
| 一直闪、一直转、满屏粒子 | 动作有开始有结束 |
| 只看代码不看画面 | 必须抽帧看图 |

## 3. 颜色

只用 `src/parts/palette.ts` 里的：

| 名字 | 值 | 含义 |
|---|---|---|
| 纸 `PAPER` | `#F4ECDA` + 纸纹 + 浅波点 `#D8C6A2` | 底，永远不抢戏 |
| 墨 `INK` | `#2B211C` | 线、正文、硬投影 |
| 黄 `YEL` | `#F7C64A` | 注意这里：大字、高亮 |
| 红 `RED` | `#D9362B` | 打击点：结论、警告、圈重点 |
| 绿 `GRN` | `#4E8A4A` | 对、通过、完成 |
| 蓝 `BLU` | `#3F6FB5` | 说明、中性 |
| 米白 `CREAM` | `#FFFDF6` | 卡片底 |
| 浅贴纸 | `SOFTY #FCE38A` `SOFTR #FFD3C9` `SOFTB #CFE3F5` `SOFTG #D9EFC8` | 大面积填色 |

- 颜色有语义：红只给打击点，到处都红就没有重点
- 大面积用浅色，饱和色留给大字和关键形状；一帧里饱和色最多两种
- 几个并列对象（四条路、三个方案）各给一个固定颜色，全片不变
- 背景只用一种颜色的波点；不用紫蓝渐变、霓虹、深色科技风

## 4. 形状语言

所有东西要像同一只手画的：

- 5~8px 墨色粗边
- 向右下的**硬投影**，不带模糊：`9px 11px 0 #2B211C`
- 四个角略不一样的圆角：`24px 30px 20px 28px`
- 轻微倾斜 ±1~3°，贴纸、印章可以 ±6~10°
- `className="boil"` 让线条微微颤动（约 10fps 手绘节奏）；人物用 `ink-line`（墨线描边 + 颤动）
- 物件内部的小动画用“一拍二”（每 2 帧变一次）

**道具要一眼认得出**：工具箱打开要像打开的工具箱。画不好就换物件，或者不要。

**形状要干净**：叠加的形状裁在轮廓里，不能露棱角；SVG 加 `overflow: visible` 并给描边留边距。

**3D 里别让平面侧成一条线**：门不要 rotateY 开（会变成一条白线），用 `scaleX + skewY` 画“推开”。

## 5. 构图

- **一个画面一个主体**，最多再加一两个辅助
- **内容占 2/3，留白 1/3**：用居中、对称或黄金分割。`framing.ts` 默认把每块展板缩到 0.84，让内容约占画面 2/3；个别展板内容特别大或特别小时单独调
- **先居中，再让位**：开场第一帧画面和第一个元素在正中；后面的元素进来时，前一组再滑开（`dx={slideX(f, at, 偏移)}`）
- **不要“左边有图、右边空着”**：用对称两栏 / 三栏或居中
- **并排的东西**等宽、上下居中、间距相同
- **不遮挡、不出画**：元素之间不能压字，不能被镜头切到画外；重叠的元素用 `lift` 分层
- **铺满但不贴边**：横屏内容在 y 40~930，960~1060 留给字幕；主体高度不到可用高度一半时，先放大，而不是加东西填空
- **没有固定装饰**：不要章节条、页码、角标、线圈装订条、可有可无的虚线框、尖刺光芒、四周小圆点
- **背景贴纸**（`World3D` 的 doodles）只在画面四周、和主题沾边，每块展板换一套、布局也换；`SHOW_DOODLES = false` 可关
- **背景和组件互动要克制**：盖章时地面波点被波纹扫一下，全片约 10 秒最多一次
- **重点组件聚焦**：重点出来时后面整个画面盖一层 0.6 的半透明纸色，组件放大到屏幕中间（`Overlay.tsx` 的 `FOCUS` + `Big`）

## 6. 字

- **按手机算字号**（1920 画布）：漫画大字 110~240，胶囊 / 标签 50~80，卡片字 48~90，字幕 56；最小 32
- **字绝不能超出框**：便签、卡片、标签、招牌按字数估宽，用 `fit(文字, 最大宽, 字号)` 算字号；长的缩字号或缩文案；标题 `whiteSpace: "nowrap"`
- **画面字不复述字幕**：只留关键词、数字、结论
- **爆点词要有动作**：跳起、盖章、爆炸框；只换文字内容不算动画
- **英文词不拆行**
- 字体：`HarmonyOS Sans SC` → `PingFang SC` → `Microsoft YaHei` → `Noto Sans SC`，加粗 900

## 7. 人物

- 模板自带一套代码画的通用角色，在 `public/img/c/`：讲解员（`stick` 拿教鞭 / `chin` 托腮 / `shrug` 摊手 / `thumb` 点赞 / `tea` 端杯子）、小同学或新人（`kid` 开心 / `q` 疑惑 / `shock` 惊讶 / `sad` 沮丧 / `hand` 举手）、`boss` 老板。由 `node scripts/make-cast.mjs` 生成，可以改里面的颜色和配件
- **用户有自己的角色形象**（IP、头像、吉祥物）：按同样的文件名把图放进 `public/img/c/`（透明底 PNG，脚底贴底边），再跑 `node scripts/make-cast.mjs --sizes` 更新 `src/charSizes.ts`。缺的姿势可以先拿相近的图顶上，告诉用户缺哪几张
- **放不放人物按内容**：讲数据可以不放；放了就要有事做（换姿势、走动、说话），讲完自己那句就退场
- 一个分镜不要只放一个人物撑整句（“又变单调了”）
- 不加小号装饰角色；人物走路脸朝前进方向（`Actor` 会自动翻面）
- 人物说话要像真人：嘴型跟着字走、有快有慢，说话时 Q 弹一下，不说话时轻轻呼吸

## 8. 真实感

- **画面不贴“示意”标签**；有真实素材（截图、评论、账单、实测数据）就放真实素材
- **出处用贴纸标**：“官方文档”“公开报道”“打个比方”
- **打码**：API Key、邮箱、手机号、账号 ID、别人的头像昵称（`scripts/blur.cjs`），打完放大确认；发现真实 Key 提醒用户去平台作废重建
- **网址、产品名、logo 用真实的**；不确定就问

## 9. 竖屏

用户要 9:16（1080×1920）时：`Root.tsx` 改尺寸；内容铺满 y 80~1550，字幕约 y 1580、62 号；避开短视频平台的顶部状态栏、右侧点赞列、底部文案区；元素整体放大，空白别留太多。
