# 写口播稿

默认观众：对这个话题感兴趣、但不是专业的人（“小白”）。在手机上刷到，不暂停，三秒内决定划不划走。用户说了自己的观众是谁，就按用户的。

**讲解人设由用户决定**：讲解人怎么自称、怎么称呼观众、账号叫什么、固定结尾怎么说，先看工程里 `taste-log.md` 的“人设”一节；没写就在写稿前问用户一次，记进 `taste-log.md`。用户不想定，就用“我”自称、对观众说“你”，结尾只说“关注我，下期见”。下文例子里的“我”都按人设替换。

## 1. 写之前

**先查清楚再写。** 讲产品就看官方文档 / 定价页 / 源码；讲新闻就找原始报道。凭印象写的事实是最常被用户打回来的（原话：“你不要给我出现 AI 幻觉啊”）。查不到的地方写【待核实：……】留给用户，不要编。

**找这期最强的一点**，再决定结构：

| 这期最强的是 | 用什么结构 |
|---|---|
| 一个很准的比喻 | 比喻优先：开头场景代入 → 用比喻把整件事翻译一遍 |
| 一个反直觉的数字 | 数据反转：开头甩数字 → 为什么 → 算给你看 |
| 一个大家常说错的词 | 辟谣：列 2~3 种常见误会 → 讲对的定义 |
| 几条并列的方法 / 坑 | 清单：一句话交代为什么要听 → 逐条，每条一个画面 → 对照表 |
| 一次真实的实测 | 实测：先说标准答案 / 规则 → 过程 → 结果 → 结论和局限 |

**选题标题框收益，不框概念。** “X 是什么”不如“X 能帮你干什么 / 你为什么总是 Y”。

## 2. 结构

1. **钩子（前 3 句）**：不用“大家好 / 今天聊聊 / 近年来”。用一个具体场景、一个反差数字、一句观众心里的抱怨，或“为什么我的 X 能 A，你的却只能 B？”。画面要能在前 10 秒把这个钩子演出来
2. **交代要讲什么**：一两句点名这期会讲哪几件事，最好许诺一个能截图的东西（对照表、清单）
3. **主体**：每段由观众心里的一个问题开头（“那是不是越多越好？还真不是”），替观众说出误解再翻转
4. **收尾三件套**：
   - “那么讲到这里……简单来说，A 是 B，X 是 C”（一句话把主比喻收回来）
   - 一句能被复述的金句
   - 一个互动问题 + 固定结尾（按人设，例如“关注我，下期见！”）

主体段落别超过 4~5 个并列项，多了观众记不住；能压成 3 个就压成 3 个。

## 3. 语言

- **说人话**：像在给朋友讲。短句为主，多用“你”。不用“其次 / 综上所述 / 因此 / 本质上”
- **口吻**：按人设；默认“我”自称，对观众说“你”
- **写段落，不写字幕行**：稿子是完整段落，拆字幕是第 2 步的事
- **没有废话**：写完试着砍三分之一，意思没丢就砍。8 分钟的稿子被说“很多废话”，同样内容 3 分钟就讲完了
- **核心比喻讲详细，其余讲简短**；字数服从内容，不卡死，最多约 2500 字
- **第一人称（“我”或人设里的自称）只在情绪高点出现**，后面紧跟一个硬信息
- **数字要写清单位**：“一个月 20 次”和“一次两块五”放在一起时，单位要说出来（次、块、分钟、还是 GB）
- **名字按真实的写**：产品名、网址用真实的；听不清的英文名不要猜

## 4. 比喻

**一个主比喻贯穿全片**：比如“用 AI 就像吃饭”——模型是大厨，四种付费方式是四种吃法；“Agent 是新来的实习生”——项目文件夹是工位，规则文件是墙上的守则。观众不用每段重新理解一次，画面也能一路复用同一套物件。机制细节可以再配小比喻。

**比喻要准。** 比喻是用来解释的，不准就是误导：API Key 是厂商发给你的办事证，不是你自己的工牌；按用量收钱不是按次数。用户问“这个形容恰当吗”时，老实指出不准的地方。

**主比喻同时决定画面**：写比喻时就想好它能画成什么物件、物件能做什么动作。画不出来的比喻要换。

## 5. 诚实

- **分清来源**，稿子里说出来：“官方文档写着……”“报道说……”“打个比方……”“我自己的理解是……”
- **没人实测的东西**，只讲它是什么，不下“别装 / 很好用”的判断；不把报道里内部版的能力说成公开版的
- **会过期的信息**（价格、限额、版本）说一句“这些一直在变，用之前去官网看一眼”
- **主动讲局限**：结尾前一句“当然我也得说句实话……”能提高可信度

## 6. 稿子格式

```markdown
# <推荐标题>

- **推荐标题**：……
- **备选标题**：……／……／……（不同角度：收益 / 痛点 / 反常识 / 数字）
- **主比喻**：……（顺便写画面方向：主要物件是什么）
- **事实来源**：每个关键事实一行，写链接或文档名
- **字数**：约 N 字，按每秒 4.5~5 字约 X 分钟
- **需要你确认 / 补充**：带【】的地方逐条列出
```

## 7. 改稿

- 一轮轮在对话里改，用户说“可以了 / 没问题 / 开始做”才进入下一步
- 用户在自己改过的版本上让你优化：只动用户指出的地方，别整篇重写
- 用户参考别人的稿子：借结构和节奏，不照搬句子和比喻
- 用户录音时可能会改说法：之后一律以录音为准
